## 4. 验收命令

```bash
# (1) 生成 OpenAPI 类型
cd AnotherMe/packages/api-client
pnpm generate:offline      # 期望：[generate] Wrote types to .../generated.ts
pnpm build                 # 期望：无 TS 错误

# (2) 移动端类型 + capability 测试
cd ../../mobile
pnpm typecheck             # 期望：exit 0，无错误
pnpm test:capability       # 期望：通过 13 / 失败 0

# (3) Python 网关语法
cd ../AnotherMe/anotherme2_engine
python -c "import ast; ast.parse(open('api_gateway/routes/ai_chat.py').read())"  # 期望：无输出
```
